2. AOSP Camera Watch

Android 16 Camera2: 프로 카메라 제어가 더 세분화됨

Android 16은 hybrid auto-exposure, 정밀 색온도/틴트 조정, night mode scene detection, motion photo capture intent, UltraHDR HEIC 관련 개선을 추가합니다. HAL 입장에서는 capability 광고와 request/result metadata 일관성이 더 중요해집니다.

  • Hybrid AE priority mode와 result metadata가 실제 센서 제어와 맞는지 확인합니다.
  • 색온도/틴트 요청이 AWB, ISP color correction, preview/capture 결과와 충돌하지 않는지 봅니다.
  • Night mode indicator가 조도 경계에서 과도하게 흔들리지 않는지 검증합니다.

CameraX 1.6: CameraPipe와 feature group 흐름을 주시

CameraX 1.6.0 release candidate/beta 라인은 CameraPipe 기반 통합 camera stack, dynamic camera add/remove detection, video stabilization feature grouping, Media3 muxer migration 관련 수정이 핵심입니다.

  • CameraX sample로 supported feature group matrix를 뽑아 Camera2 native dump와 비교합니다.
  • Preview stabilization + video capture + image capture 조합에서 stream 재구성과 failure path를 확인합니다.
  • JPEG encoder padding path가 있다면 Exif/JPEG parser 호환성 회귀 테스트를 추가합니다.

3. Tech Trend Radar

Agent 도구는 실행보다 운영 문제가 커지는 중

GitHub는 Copilot cloud agent 사용량 지표를 추가했고, Copilot code review가 2026-06-01부터 GitHub Actions minutes를 소비한다고 공지했습니다. OpenAI는 Codex orchestration을 위한 open-source spec인 Symphony를 공개했습니다.

  • Agent 사용량을 repo, 사용자, 작업 유형별로 측정해야 합니다.
  • HAL 로그 분석, flaky test triage, CL 리뷰, 문서 업데이트처럼 반복 작업부터 agent 후보로 잡는 편이 안전합니다.
  • Agent가 낸 결론은 관련 log line, failing test, suspected module, reproduction condition 같은 증거와 함께 받아야 합니다.

Clang/LLVM 21: HAL native code에도 유용한 진단과 분석 포인트

LLVM/Clang 21.1.0에는 -ftime-report-json, -Wnrvo, static analyzer 개선 등이 포함됩니다. 큰 HAL module의 build cost, value copy, callback/lifetime bug를 좁히는 데 활용할 수 있습니다.

4. 이번 주 C++ / AI 실전 팁

AI에게 Camera HAL 로그를 맡길 때는 증거 표를 강제하라

로그 분석에서는 결론보다 증거가 먼저입니다. AI에게 timeline, suspicious points, request-result mapping, buffer lifecycle, 다음 실험을 표로 내도록 요구하면 답변이 바로 triage artifact가 됩니다.

출력 형식:
1. Timeline 표: timestamp / thread / event / 근거 log line
2. Suspicious points 표: 의심 지점 / 관련 module / 근거 / 반증할 방법
3. Request-result mapping: frame number 기준 request metadata와 result metadata 연결
4. Buffer lifecycle: acquire / process / release / error 경로
5. 다음 실험 3개: 재현 조건, 추가 로그, 기대 결과
