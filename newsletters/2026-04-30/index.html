AOSP Camera Watch

CameraX 1.6 + Android 17: 이제 “지원한다고 말한 기능”이 더 빨리 검증된다

CameraX는 앱 개발자용 라이브러리지만, HAL 입장에서는 상위 호환성 테스트 도구처럼 동작합니다. CameraX 1.6은 CameraPipe 기반 unified stack, Media3 Muxer, Feature Group 개선, stable SessionConfig, isSessionConfigSupported()를 포함합니다.

핵심은 간단합니다. 앱이 bind 전에 조합 지원 여부를 더 쉽게 묻고, HAL은 capability와 실제 동작을 더 일관되게 맞춰야 합니다. 추상화는 친절하지만, 거짓말에는 집요합니다.
영역Camera HAL 점검 포인트
CapabilityisSessionConfigSupported() 결과와 HAL configure_streams() 성공 여부가 일치하는지 확인
Dynamic RangeAndroid 17 dynamic range mode가 metadata / framework path에서 unknown으로 누락되지 않는지 확인
StabilizationPreview stabilization, Video stabilization, 4K recording 동시 요청에서 capability와 실제 동작이 모순되지 않는지 확인
Stream / BufferPreview + VideoCapture + ImageAnalysis + Extension 조합에서 buffer starvation, reconfigure loop, abandoned surface 로그 확인

Sources: CameraX release notes, Android 17 Beta 4

AOSP Camera Watch

Android 17 Beta 4는 마지막 scheduled beta로 소개되었고, SDK/library/tool 개발자에게 호환성 준비가 권고되었습니다.

Android 17 Beta 4

Camera App smoke test를 지금 고정해야 한다

Android 17 target에서는 native library loading 보호가 강화되고, app memory limit과 profiling trigger가 추가됩니다. Camera App의 long-run preview, video, high-resolution capture에서 메모리와 binder spam을 같이 봐야 합니다.

  • native library file permission 확인
  • ApplicationExitInfo의 MemoryLimiter 흔적 확인
  • ProfilingManager anomaly trigger로 excessive binder calls 분석
CameraX 1.6

SessionConfig가 HAL 조합 검증의 입구가 된다

SessionConfig가 stable public API가 되고, feature group이 video stabilization과 4K recording을 지원하면서 앱이 더 많은 조합을 더 쉽게 요청할 수 있습니다.

  • HDR + stabilization + resolution 조합표 작성
  • logical/physical camera id별 차이 확인
  • vendor tag와 public metadata 간 불일치 점검

On-device AI Watch

Hybrid inference / LiteRT / NPU

AI 기능은 이제 Camera 성능 이슈와 같은 방에 들어왔다

Firebase hybrid inference는 on-device Gemini Nano와 cloud-hosted Gemini model을 unified API로 전환할 수 있게 합니다. LiteRT는 CPU/GPU/NPU acceleration을 제공하며, real-time video effects 같은 기능에서 thermal, battery, frame drop이 핵심이라고 설명합니다.

영역점검 포인트
ThermalPreview + AI inference 동시 구동 시 FPS drop / throttling 상관관계 측정
BufferBitmap 변환, format conversion, stride mismatch, copy count 확인
Privacyon-device/cloud fallback 정책과 image data 반출 정책 충돌 여부 확인
