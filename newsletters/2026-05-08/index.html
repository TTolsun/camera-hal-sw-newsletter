2. Android Platform Camera Adjacent

CameraX 1.6.1 릴리스: Camera Maven Group 버전 갱신 확인

확인한 사실
  • 버전/릴리스: CameraX 1.6.1
  • 게시일: May 06, 2026
  • API/컴포넌트: CameraX / `androidx.camera`
  • 수집 evidence에는 Camera Maven Group 버전 표와 CameraX 관련 artifact 이름이 포함됩니다.
배경지식

CameraX는 Android app 계층에서 Camera2 기반 camera 기능을 다루는 Jetpack library입니다. HAL 팀 입장에서는 CameraX 자체가 HAL contract를 바꾸는 출처는 아니지만, app 계층 regression이나 stream use case 재현에 자주 쓰이는 compatibility signal입니다.

Camera HAL 관점

HAL 팀은 이 release note를 새 HAL 요구사항의 근거로 쓰지 말고, 기존 Camera2 / CameraX 호환성 test matrix의 dependency version을 확인하는 입력으로 사용해야 합니다. 특히 `StreamConfigurationMap`, session configuration, preview/video/image capture 조합은 기존 CDD, CTS/VTS, Camera ITS 기준 안에서 regression 여부만 확인합니다.

실행 항목
  • CameraX 1.6.1 dependency로 preview + image capture + video capture smoke test를 실행하고 실패한 stream 조합만 issue로 분리합니다.
  • `dumpsys media.camera`와 app logcat에서 session configuration 실패가 있는지 확인해 기존 HAL regression과 app/library issue를 구분합니다.
팀 공유 포인트

CameraX 1.6.1은 HAL 요구사항 변경 뉴스가 아니라 compatibility test 입력입니다. 이번 주에는 CameraX version 기준을 고정하고 기존 Camera HAL validation matrix에서 regression만 확인하면 됩니다.

3. Camera Driver / Image Pipeline

libcamera v0.7.1: SoftISP와 image pipeline 릴리스

확인한 사실
  • 버전/릴리스: libcamera v0.7.1
  • 게시일: 2026-04-28
  • API/컴포넌트: libcamera / V4L2 camera pipeline
  • 수집 evidence에는 SoftISP debayering, image pipeline throughput, pipeline handler camera support, sensor mode configuration updates가 포함됩니다.
배경지식

libcamera는 Linux camera stack에서 V4L2, sensor, pipeline handler, image processing 경로를 추상화하는 project입니다. Android device가 libcamera를 직접 쓰지 않더라도, vendor bring-up이나 Linux-based camera validation 환경에서는 driver pipeline behavior를 비교하는 참고점이 됩니다.

Camera HAL 관점

HAL 팀은 libcamera v0.7.1을 Android HAL contract 변경으로 해석하지 않습니다. 다만 vendor kernel, V4L2 bridge, external camera validation stack이 libcamera와 맞닿아 있다면 RAW/YUV path, sensor mode selection, frame timing을 기존 HAL KPI와 같은 방식으로 비교할 수 있습니다.

실행 항목
  • libcamera v0.7.1 적용 platform이 있는지 vendor kernel / BSP branch 기준으로 확인하고, 해당 platform만 regression 대상에 넣습니다.
  • RAW/YUV capture path에서 frame timing, sensor mode, media graph log를 수집해 기존 HAL KPI와 비교합니다.
팀 공유 포인트

libcamera v0.7.1은 Linux camera driver / image pipeline 쪽 release입니다. HAL 팀은 직접 적용 여부를 platform별로 확인하고, 관련 platform에서만 RAW/YUV path와 sensor mode regression을 비교하면 됩니다.

4. C++ / AI Tooling Fallback

GCC 16.1: C++26 reflection / contracts 지원 동향

확인한 사실
  • 버전/릴리스: GCC 16.1
  • 게시일: 2026-04-30 (Thu, 30 Apr 2026 22:36:23 +0000)
  • API/컴포넌트: GCC
  • 수집 evidence는 GCC 16.1 release와 C++26 reflection / contracts / safety hardening / C++20 by default 항목을 포함합니다.
배경지식

Camera HAL native code는 AOSP build 환경에서 주로 Clang/LLVM, libc++, Android platform toolchain 정책에 맞춰 관리됩니다. GCC 16.1 소식은 Android HAL에 즉시 적용되는 변경이 아니라 C++ 표준 기능과 compiler support 흐름을 장기 관찰하는 정보입니다.

Camera HAL 관점

HAL 팀은 GCC 16.1을 Android HAL build 변경으로 해석하지 않습니다. 대신 Clang/LLVM 쪽 지원 현황과 AOSP coding guideline을 함께 확인하면서, metadata table generation, request/result validation helper, compile-time checks 같은 native tooling PoC 후보를 장기 backlog로만 기록합니다.

실행 항목
  • HAL native build 설정에서 compiler와 C++ standard flag를 확인하고, GCC 16.1 관련 기능을 production requirement로 등록하지 않습니다.
  • metadata serialization 또는 `camera3_request` validation helper에 대한 compile-time check PoC가 필요하면 Clang/LLVM 지원 현황을 먼저 확인합니다.
팀 공유 포인트

GCC 16.1은 Android HAL 직접 변경 뉴스가 아닙니다. 이번 호에서는 native C++ tooling watch item으로만 보관하고, 실제 HAL 적용은 Clang/LLVM과 AOSP policy 확인 이후 별도 PoC로 제한합니다.
